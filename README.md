## 📖 Sobre

Front-end de um cardápio digital para uma lanchonete, no estilo de apps de delivery. O cliente monta o pedido, informa o endereço e finaliza — e o pedido é enviado formatado para o WhatsApp do estabelecimento. Projeto feito para praticar **JavaScript puro** e **Tailwind CSS**.

## ✨ Funcionalidades

- 🛒 **Carrinho de compras** — adicionar itens, aumentar/remover quantidade e total atualizado em tempo real
- 💰 Valores formatados em **Real (BRL)**
- 📍 **Validação de endereço** antes de finalizar o pedido
- 🕒 **Verificação de horário de funcionamento** (bloqueia pedidos com o estabelecimento fechado)
- 🔔 Notificações de feedback com **Toastify**
- 📱 **Envio do pedido pelo WhatsApp** com os itens e o endereço
- 💻 Layout **responsivo** (mobile e desktop)

## 🛠️ Tecnologias

- **HTML5** e **JavaScript** (vanilla)
- **Tailwind CSS** para estilização
- **Toastify.js** para notificações

## 🚀 Como executar

```bash
# Clone o repositório
git clone https://github.com/Erikjuniorsilva/cardapio-lanches.git
cd cardapio-lanches

# Instale as dependências (Tailwind)
npm install

# Gere o CSS do Tailwind em modo watch
npm run card
```

Depois é só abrir o `index.html` no navegador (ou usar uma extensão como o *Live Server*).
